# 🧙 SQL Oracle & Cloud Data Warehouse

> Assistente de conhecimento sobre SQL e Cloud Data Warehouse criado com NotebookLM durante o Bootcamp **IA com Dados — Bradesco & DIO**.

---

## 🎯 Objetivo

O projeto nasceu com a proposta de transformar conteúdos técnicos sobre **SQL e plataformas de Data Warehouse em nuvem** em uma base de conhecimento consultável de forma mais rápida e contextual.

Em vez de apenas reunir materiais, a ideia foi organizar referências e utilizar o **NotebookLM** como camada de interação para apoiar estudo, comparação de tecnologias e consulta conceitual.

---

## 🧩 Problema trabalhado

Quem está estudando dados frequentemente encontra informações espalhadas entre documentação, artigos e materiais de curso. Comparar soluções como **Amazon Redshift, Google BigQuery e Snowflake** exige entender diferenças de arquitetura, escalabilidade, gerenciamento e casos de uso.

O projeto organiza esse conteúdo em uma experiência única de consulta.

---

## 💡 Solução

O SQL Oracle utiliza uma base de conhecimento curada no NotebookLM para apoiar perguntas e análises sobre:

- SQL e conceitos relacionados a Data Warehouse;
- **Amazon Redshift** e arquitetura MPP;
- **Google BigQuery** e abordagem serverless;
- **Snowflake** e separação entre armazenamento e computação;
- comparação entre diferentes modelos de Cloud Data Warehouse;
- cenários e critérios para escolha de tecnologia.

---

## 🧠 Como o projeto foi construído

**Curadoria de conteúdo → organização das fontes → criação da base de conhecimento → interação via NotebookLM → comparação e síntese dos conceitos**

O foco do projeto não é substituir documentação oficial, mas demonstrar como **IA generativa pode apoiar organização, estudo e recuperação de conhecimento técnico**.
