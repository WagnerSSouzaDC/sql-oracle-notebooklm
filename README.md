Assistente inteligente de SQL e Cloud Data Warehouse criado com NotebookLM para o bootcamp DIO/Bradesco.

# 🧙‍♂️ SQL Oracle & Cloud Data Warehouse Insights

## 📋 Sobre o Projeto
Este projeto foi desenvolvido durante o Bootcamp **IA com Dados (parceria Bradesco & DIO)**. O objetivo foi criar um "Oráculo de SQL" utilizando o **NotebookLM** do Google, transformando uma base de conhecimento técnico em um assistente inteligente.

## 🧠 Capacidades do Oráculo
Com base na curadoria de dados realizada, o assistente fornece insights sobre:

* **Amazon Redshift:** Arquitetura de Processamento Paralelo Massivo (MPP) e alta performance.
* **Google BigQuery:** Escalabilidade em modelo Serverless com baixo gerenciamento.
* **Snowflake:** Diferenciação por sua arquitetura de separação entre armazenamento e computação.

## 🚀 Tecnologias e Metodologia
* **NotebookLM:** Interface de IA para processamento de documentos específicos.
* **Análise Comparativa:** Base de dados estruturada comparando modelos de cobrança, manutenção (SaaS vs Gerenciado) e casos de uso de Cloud Data Warehouse.
* **SQL Avançado:** Foco em otimização de queries e suporte multi-plataforma.
